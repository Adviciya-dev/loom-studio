# Prompt: Create React Page

```
Read these files first:
1. harness/claude.md
2. harness/tasks/TASK-XXX.md

Create a React page for [PAGE_NAME]:
- Use TypeScript with proper interfaces
- Use React Query for data fetching (useQuery/useMutation)
- Use Tailwind CSS for styling
- Use shared components from src/shared/components/
- Handle loading, error, and empty states
- Mobile responsive

Do NOT use inline styles.
Do NOT use useState for server data — use React Query.
Do NOT make API calls directly — use service files.
```
